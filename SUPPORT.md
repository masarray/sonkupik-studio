# SONKUPIK STUDIO Support

## Before opening a public issue

1. Confirm that the package came from the [official latest release](https://github.com/masarray/sonkupik-studio/releases/latest).
2. Verify the exact file against `SHA256SUMS.txt` from the same release.
3. Restart the processor and Windows computer, then reconnect through the intended USB HID or Bluetooth path.
4. Reproduce the problem with one known preset and the smallest possible number of steps.
5. Remove customer names, venue data, private presets, device identifiers, credentials and commercial project information.

## Include this information

- SONKUPIK STUDIO version;
- Setup or Portable package;
- Windows edition, version and architecture;
- processor model, visible hardware revision and firmware version when available;
- USB HID or Bluetooth connection path;
- exact page, channel and control involved;
- expected behavior;
- actual behavior;
- complete reproduction steps;
- whether the issue remains after reconnecting and reading the device again; and
- screenshots or logs only after private information has been removed.

## Safety boundaries

Do not publish:

- customer or venue identities;
- private preset libraries or commercial tuning files;
- passwords, tokens, serial numbers or unique device identifiers;
- confidential audio, project files or order records; or
- exploit details for an unpatched security issue.

Use the process in [SECURITY.md](SECURITY.md) for security-sensitive reports.

# Dukungan SONKUPIK STUDIO

## Sebelum membuka issue publik

1. Pastikan package berasal dari [rilis resmi terbaru](https://github.com/masarray/sonkupik-studio/releases/latest).
2. Verifikasi file yang persis menggunakan `SHA256SUMS.txt` dari rilis yang sama.
3. Restart prosesor dan komputer Windows, lalu hubungkan kembali melalui jalur USB HID atau Bluetooth yang dimaksud.
4. Reproduksi masalah memakai satu preset yang diketahui dan langkah sesedikit mungkin.
5. Hapus nama customer, data venue, preset privat, identitas perangkat, credential dan informasi project komersial.

## Sertakan informasi berikut

- versi SONKUPIK STUDIO;
- package Setup atau Portable;
- edisi, versi dan arsitektur Windows;
- model prosesor, revisi hardware yang terlihat dan versi firmware bila tersedia;
- jalur koneksi USB HID atau Bluetooth;
- halaman, channel dan kontrol yang terlibat;
- perilaku yang diharapkan;
- perilaku aktual;
- langkah reproduksi lengkap;
- apakah masalah tetap terjadi setelah reconnect dan membaca ulang perangkat; serta
- screenshot atau log hanya setelah informasi privat dihapus.

## Batas keamanan

Jangan publikasikan:

- identitas customer atau venue;
- library preset privat atau file tuning komersial;
- password, token, serial number atau identitas perangkat unik;
- audio rahasia, file project atau catatan order; maupun
- detail eksploit untuk masalah keamanan yang belum diperbaiki.

Gunakan proses di [SECURITY.md](SECURITY.md) untuk laporan yang sensitif terhadap keamanan.
