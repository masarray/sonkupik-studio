Frequently asked questions

Before you download or buy a K500

Short answers to the questions that usually make first-time users hesitate.

What is SONKUPIK STUDIO?

SONKUPIK STUDIO is an independent desktop application for controlling, tuning, reading, comparing and managing presets on compatible KTV PRO K500 processors. It does not replace the K500 hardware; it acts as its PC control room.

Do I need a KTV PRO K500?

Yes for live device control. You can download the app without a K500, but reading and writing hardware parameters requires a compatible K500 unit.

Is SONKUPIK STUDIO free?

Yes. The public SONKUPIK STUDIO packages are free to download from this page. The primary button points directly to the latest Windows installer.

Which Windows versions are supported? What about macOS and Linux?

The current public distribution targets Windows 10/11 64-bit. macOS and Linux packages are not available yet; their buttons remain disabled so the page never suggests an installer exists when it has not been released.

How do I connect the K500 to SONKUPIK STUDIO?

Connect the K500 through a compatible USB HID or Bluetooth path, then select the device and read its state from the app. Actual support can vary by hardware revision, firmware and Windows configuration.

Setup or Portable: which should I choose?

Setup is recommended for everyday use and faster startup. Portable is useful when you do not want a permanent installation or need a more flexible location.

Windows SmartScreen appears. Is the file corrupted?

Not necessarily. The current Windows binaries are not code-signed, so Windows can display a publisher warning. Use the SHA-256 checksum from the same release to verify the file you downloaded.

The K500 is not detected. What should I do?

Restart the K500 and Windows computer, reconnect through the intended USB HID or Bluetooth path, then read the device again. If it still fails, note your SONKUPIK STUDIO version, Windows version, K500 revision and connection path.
