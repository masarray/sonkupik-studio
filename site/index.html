Yang bisa dilakukan

Satu aplikasi untuk setting, kontrol, dan preset K500.

Tidak perlu memahami struktur repo atau file engineering. Install, hubungkan perangkat, lalu bekerja dari satu control room.

LIVE CONTROL

Kontrol perangkat langsung

Baca dan ubah parameter K500 melalui USB HID atau Bluetooth dari satu workspace desktop.

PRESET

Simpan dan recall setting

Kelola preset PC, baca slot perangkat, bandingkan setting, mass upload, dan simpan permanen.

PEQ

EQ yang mudah dibaca

Atur parametric EQ untuk mic, music, effect dan output dengan visual yang lebih jelas.

VOCAL FX

Reverb dan echo terpisah

Kelola karakter vokal dengan kontrol effect yang fokus tanpa mencampur semuanya dalam satu blok.

SPEAKER

Crossover dan delay

Atur HPF, LPF, routing, level dan alignment untuk Main, Surround, Center dan Subwoofer.

WORKFLOW

Lebih cepat saat tuning

Kurangi setting berulang dengan preset, readback, compare dan kontrol yang konsisten.

Mulai dalam tiga langkah

Download. Hubungkan. Atur.

Alur dibuat untuk pengguna biasa maupun teknisi yang ingin langsung bekerja.

01

Install SONKUPIK STUDIO

Klik Windows Setup di atas. Installer adalah pilihan yang direkomendasikan karena startup lebih cepat daripada Portable.

02

Hubungkan K500

Sambungkan prosesor melalui jalur USB HID atau Bluetooth yang didukung, lalu pilih perangkat dari aplikasi.

03

Tuning dan simpan

Atur parameter, dengarkan hasilnya, simpan preset PC, atau tulis ke slot perangkat yang dituju.

Perangkat yang dikontrol

SONKUPIK STUDIO dibuat untuk KTV PRO K500.

Landing page ini berfokus pada software. K500 adalah hardware DSP yang dikontrol oleh aplikasi untuk live tuning dan manajemen preset.

  • Live control melalui USB HID dan Bluetooth
  • PEQ, dynamics, vocal effects, crossover dan output management
  • Preset PC, readback, compare, mass upload dan permanent store
Belum punya K500?

Anda tetap dapat mengunduh aplikasi sekarang. Untuk live control, diperlukan perangkat KTV PRO K500 yang kompatibel.

Pertanyaan singkat

Sebelum download

Apakah installer membawa saya ke GitHub?

Tidak. Tombol Windows Setup dan Portable diarahkan langsung ke file release resmi. GitHub hanya dipakai sebagai host distribusi dan release notes.

Kenapa macOS dan Linux belum bisa diklik?

Release publik saat ini hanya memiliki binary Windows. Tombol macOS/Linux sudah disiapkan dan akan aktif otomatis ketika paket resminya tersedia.

Setup atau Portable?

Gunakan Setup untuk pemakaian harian dan startup lebih cepat. Portable cocok jika Anda tidak ingin instalasi permanen.

Windows menampilkan SmartScreen?

Binary saat ini belum code-signed, sehingga Windows dapat menampilkan peringatan publisher pada first launch. Verifikasi SHA-256 tersedia di halaman ini.

Siap menggunakan SONKUPIK STUDIO?

Download installer resmi terbaru untuk Windows. Tidak perlu membuka folder repo atau mencari file release secara manual.
