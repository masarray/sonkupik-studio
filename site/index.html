Frequently asked questions

Will it work with every karaoke processor?

No universal compatibility is implied. SONKUPIK STUDIO targets compatible K500-family workflows; device revision, firmware, connection method and Windows configuration can affect behavior.

Which package should I use?

Use Setup for normal daily operation and faster startup. Use Portable when installation is not possible or a self-contained copy is required.

Does this repository contain the application source?

No. This repository is the public product website and binary distribution surface. The application is built from the separate source repository.

Does the website upload audio or include tracking?

The website does not process audio and contains no advertising or analytics code. It contacts GitHub only to resolve current official release information.

Where should I report a reproducible problem?

Read the public support guide, remove private customer or device information, then open an issue in the distribution repository.
