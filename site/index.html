Yang bisa dilakukan

Satu aplikasi untuk setting, kontrol, dan preset K500.

Tidak perlu memahami struktur repo atau file engineering. Install, hubungkan perangkat, lalu bekerja dari satu control room.

LIVE CONTROL

Kontrol perangkat langsung

Baca dan ubah parameter K500 melalui USB HID atau Bluetooth dari satu workspace desktop.

PRESET

Simpan dan recall setting

Kelola preset PC, baca slot perangkat, bandingkan setting, mass upload, dan simpan permanen.

PEQ

EQ yang mudah dibaca

Atur parametric EQ untuk mic, music, effect dan output dengan visual yang lebih jelas.

VOCAL FX

Reverb dan echo terpisah

Kelola karakter vokal dengan kontrol effect yang fokus tanpa mencampur semuanya dalam satu blok.

SPEAKER

Crossover dan delay

Atur HPF, LPF, routing, level dan alignment untuk Main, Surround, Center dan Subwoofer.

WORKFLOW

Lebih cepat saat tuning

Kurangi setting berulang dengan preset, readback, compare dan kontrol yang konsisten.

Apa itu SONKUPIK STUDIO?

SONKUPIK STUDIO adalah aplikasi desktop independen untuk mengontrol, tuning, membaca, membandingkan dan mengelola preset KTV PRO K500 yang kompatibel. Software ini tidak menggantikan hardware K500; ia menjadi control room di PC.

Apakah saya harus punya KTV PRO K500?

Untuk live control perangkat, ya. Anda boleh mengunduh aplikasi tanpa K500, tetapi fungsi baca/tulis parameter hardware memerlukan unit K500 yang kompatibel.

Bagaimana menghubungkan K500 ke SONKUPIK STUDIO?

Hubungkan K500 melalui USB HID atau Bluetooth yang kompatibel, lalu pilih perangkat dan baca statusnya dari aplikasi. Dukungan aktual dapat berbeda menurut revisi hardware, firmware dan konfigurasi Windows.

Setup atau Portable, pilih yang mana?

Setup direkomendasikan untuk pemakaian harian dan startup lebih cepat. Portable cocok jika Anda tidak ingin instalasi permanen atau ingin menjalankan aplikasi dari lokasi yang fleksibel.

Windows SmartScreen muncul. Apakah file rusak?

Tidak otomatis berarti file rusak. Binary Windows saat ini belum code-signed sehingga Windows dapat menampilkan peringatan publisher. Gunakan SHA-256 checksum dari release yang sama untuk memverifikasi file yang Anda unduh.

K500 tidak terdeteksi. Apa yang harus saya lakukan?

Restart K500 dan komputer, sambungkan ulang melalui USB HID atau Bluetooth yang dimaksud, lalu baca perangkat lagi. Jika masih gagal, catat versi SONKUPIK STUDIO, versi Windows, revisi K500 dan jalur koneksinya.
