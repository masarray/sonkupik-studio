Frequently asked questions

Does this website contain the application source code?

No. This repository is the public website and binary distribution surface. The application source remains in the separate KTV Studio source repository.

Which package should I use?

Use Setup for normal daily operation and faster startup. Use Portable when installation is not possible or when you need a self-contained copy.

Will it work with every karaoke processor?

No universal compatibility is implied. SONKUPIK STUDIO targets compatible K500-family workflows. Device revision, firmware, transport and Windows configuration can affect behavior.

Does the application upload my audio?

The product is designed as a local processor-control and preset-management workflow. The public website uses GitHub only to resolve official release information and does not include advertising or analytics code.

Where should I report a reproducible problem?

Read the support guide, remove private device or customer information, then open a GitHub Issue in the public distribution repository.
