Dibangun untuk pekerjaan tuning nyata

Dari satu koreksi sampai preset venue lengkap.

Kedalaman teknis tetap tersedia tanpa membuat operator berjuang melawan software. Setiap area disusun berdasarkan tugas signal-flow yang jelas.

01 · CONTROL

Live processor control

Baca dan ubah parameter perangkat yang didukung dengan status koneksi, konteks channel dan feedback yang jelas.

02 · TUNE

PEQ dan crossover

Bentuk frequency response melalui kurva visual, nilai presisi serta kontrol high-pass dan low-pass yang channel-aware.

03 · DYNAMICS

Compression dan proteksi

Kelola gain structure, dynamics dan perilaku output dari surface engineering yang konsisten.

04 · MIX

Music, microphone dan effect

Seimbangkan jalur inti karaoke sambil menjaga hubungan input, effect dan output tetap mudah dipahami.

05 · PRESETS

Library perangkat dan PC

Recall slot hardware, pisahkan preset user dan bangun titik awal terpercaya untuk ruangan atau penyanyi berbeda.

06 · DEPLOY

Workflow mass upload

Pindahkan kumpulan preset yang telah disiapkan ke slot yang didukung melalui alur seleksi dan deployment yang deliberate.

Metode kerja yang terkendali

Hubungkan. Baca. Tuning. Simpan.

Urutan yang jelas mengurangi perubahan tidak disengaja dan membuat setiap keputusan tuning lebih mudah direview.

Hubungkan prosesor

Gunakan jalur USB HID atau Bluetooth yang didukung dan konfirmasi status live perangkat.

Baca preset saat ini

Mulai dari nilai perangkat yang nyata, bukan asumsi bahwa hardware sudah sama dengan file.

Tuning dengan konteks

Atur PEQ, crossover, dynamics dan mixer sambil melihat keseluruhan signal path.

Simpan dan deploy

Simpan salinan PC yang telah direview, tulis ke slot tujuan dan verifikasi hasilnya.

Pertanyaan yang sering diajukan

Apakah website ini berisi source code aplikasi?

Tidak. Repository ini adalah permukaan publik untuk website dan distribusi binary. Source aplikasi tetap berada di repository source KTV Studio yang terpisah.

Package mana yang sebaiknya saya gunakan?

Gunakan Setup untuk operasi harian dan startup lebih cepat. Gunakan Portable ketika instalasi tidak memungkinkan atau Anda membutuhkan salinan self-contained.

Apakah dapat bekerja dengan semua prosesor karaoke?

Tidak ada klaim kompatibilitas universal. SONKUPIK STUDIO ditujukan untuk workflow keluarga K500 yang kompatibel. Revisi perangkat, firmware, transport dan konfigurasi Windows dapat memengaruhi perilaku.

Apakah aplikasi meng-upload audio saya?

Produk dirancang sebagai workflow lokal untuk kontrol prosesor dan manajemen preset. Website publik hanya memakai GitHub untuk membaca informasi rilis resmi serta tidak memuat iklan atau analytics.

Di mana melaporkan masalah yang reproducible?

Baca panduan support, hapus informasi perangkat atau customer yang privat, lalu buka GitHub Issue di repository distribusi publik.
